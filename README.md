# GameLingo Pro

GameLingo'dan bağımsız Android uygulaması.

- Paket kimliği: `com.gamelingo.pro`
- Açılış: kısa neon logo animasyonu, hesap girişi yok
- Tema: koyu lacivert, turkuaz, mor ve pembe
- OCR ve çeviri: mevcut kaynak proje üzerinden geliştirilecek

> Android kaynak dosyaları henüz depoya aktarılmadı. Bu nedenle APK derlemesi henüz doğrulanmadı.
